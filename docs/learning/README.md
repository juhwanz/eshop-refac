# E-Shop 학습 현황

프로젝트 이해, Java/Spring 백엔드 면접과 기본 CS 복습을 위한 개인 학습 기록이다. 현재 시스템의 공식 동작은 상위 `docs/`와 코드가 기준이며, 이 디렉터리에는 질문에 답하는 과정과 교정된 이해를 남긴다.

이 파일이 **현재 진도, 자신감, 복습 일정과 약점의 단일 기준**이다. [`COVERAGE.md`](COVERAGE.md)는 빠진 지식을 확인하는 정적 범위표이고, [`ROADMAP.md`](ROADMAP.md)는 권장 학습 순서다.

## 사용 방법

- `공부 시작`: 복습 일정과 아래 `다음 학습` 순서를 기준으로 한 세션을 시작한다.
- `오늘은 <주제> 공부하자`: 지정한 주제로 진단 질문부터 시작한다.
- `복습 시작`: 복습 예정일이 지난 항목을 우선한다.
- `모의 면접 시작`: 프로젝트와 기초 질문을 섞어 한 번에 하나씩 진행한다.
- `오늘은 여기까지`: 세션·개념 문서와 이 현황판을 갱신한다.

기본 세션은 핵심 질문 3개, 압박 질문 최대 2개, 마지막 30초 답변으로 끝낸다. `설명 가능` 판정 후보일 때만 2분 답변도 확인한다. 사용자가 원하면 연장하거나 언제든 종료할 수 있다. 학습 중에는 정답을 먼저 읽지 않고 자신의 말로 답한다.

## 상태 기준

| 상태 | 기준 |
|---|---|
| 미진단 | 아직 자신의 말로 설명해보지 않음 |
| 학습 중 | 핵심은 이해했지만 후속 질문, 근거 또는 한계 설명이 부족함 |
| 설명 가능 | `COVERAGE.md`의 해당 범위 전체와 30초·2분 답변, 후속 질문 2개, 근거와 한계 설명을 완료함 |

자신감은 `미진단` 또는 1~5로 기록한다. 한 역량은 여러 세션에 걸쳐 학습할 수 있으며, 일부 범위나 문서만 완료했다는 이유로 상태를 올리지 않는다.

## 근거 표시

- `[CODE]`: 운영 코드에서 확인
- `[TEST]`: 테스트 코드나 실행 결과로 확인
- `[ADR]`: 채택된 의사결정
- `[DOC]`: 저장소 문서에 기록

- `[INFERENCE]`: 직접 검증되지 않은 추론
