# Architecture Decision Records

이 디렉터리는 장기간 유지되어야 할 중요한 기술적 의사결정을 기록한다.

## 생성 규칙

- 사용자가 ADR 기록을 승인한 경우에만 생성한다.
- 파일명은 `NNNN-short-kebab-case-title.md` 형식을 사용한다.
- `NNNN`은 기존 ADR의 가장 큰 번호에 1을 더한 4자리 일련번호다. 첫 ADR은 `0001`이다.
- 본문은 한국어로 작성하고 결정의 배경, 대안, 장단점을 간결하게 남긴다.
- 이미 채택된 결정을 바꿀 때는 기존 ADR을 삭제하거나 내용을 덮어쓰지 않고 새 ADR을 추가한다.

## 문서 형식

```markdown
# 제목

- 상태: 채택
- 날짜: YYYY-MM-DD

## 배경

결정이 필요한 이유와 제약을 작성한다.

## 결정

선택한 방안과 적용 범위를 작성한다.

## 검토한 대안

- 대안과 선택하지 않은 이유를 작성한다.

## 결과

- 기대 효과와 감수해야 할 단점 또는 후속 작업을 작성한다.
```
